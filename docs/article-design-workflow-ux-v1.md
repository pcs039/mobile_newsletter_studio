## 작업자 동선

- 처음 작업: 현재 디자인/전략 확인 → 맞춤 Canva 후보 또는 콘셉트·초안, 등록 Canva 선택 → 기존 명시적 실행 단계 → 확인.
- 기존 디자인 수정: 새 추천을 요청하지 않고 세부 조정 펼침 → 글자 버튼 저장/배치 자동 저장 → 즉시 미리보기와 상단 저장본 확인.
- 패턴만 변경: 패턴 변경 펼침 → 추천 또는 수동 선택 → 변경 예정 확인 → 기존 확인/취소. 요청 결과와 실패는 접어도 계속 보임.
- 글꼴: 기존 상단 글꼴 설정의 ‘변경’ 사용. 저장 폼/Context/RSC 경계/상속은 그대로 유지.

## 인스턴스·저장 계약

native details를 사용하며 children을 열림 여부에 따라 조건부 렌더링하지 않는다. 기존 article/template/pattern key, 요청 handler, 생성 gate, Composition 저장 hook, 기사 저장 폼과 글꼴 Context는 변경하지 않는다. 패턴 확인 시 details를 열어 변경 예정 내용을 확인할 수 있게 한다. 단순 접기·펼치기는 저장/추천/생성을 호출하지 않는다.

공개 미지원 세 슬롯(제목 옆 아이콘·본문 주변 장식·하단 배너)은 그대로 편집·저장 가능하며 제한 안내를 유지한다. ready/draft 변경, 자산 승인, 공개 조건을 통합하거나 완화하지 않는다. 공통 ArticleCard/preview renderer와 sticky/390·520/글자 확대도 변경하지 않는다.

## 검증과 한계

- 신규 UI 회귀 5개: 선택/확인 보존, 결과·오류 상시 노출, 등록 Canva 선택/오류 보존, 접힌 세부 조정 저장 상태와 preview mount.
- 전체 테스트 492/492 통과. 기존 저장 요청 순서/실패/재시도/기사 격리와 RSC deferred slot #130 회귀 테스트 포함.
- 로컬 Production Webpack 빌드 + 기존 Staging 샘플 기사로 확인: 텍스트 초안 접기·탭 전환 유지, 글꼴 저장 충돌 차단, 패턴 확인/취소, 등록 Canva 선택값 유지, 기본/최대 글자 크기와 390/520 preview.
- 실측 CSS viewport 390/768/1440에서 document scrollWidth == clientWidth. 신규 JS/React/hydration 오류 없음. 나눔고딕 바이너리 OTS 문제는 기존 이슈 #239이며 이번 범위 제외.
- 인증된 원격 Staging 확인 결과와 Vercel 상태는 구현 PR에 별도 기록한다. 실제 생성/승인/가져오기/기사 적용 API는 실행하지 않으며 기존 자동화 회귀로 계약을 확인한다.

## 영향과 후속

API/RPC/DB/Storage/dependency/migration/Production 변경 없음. 새 route·탭·디자인 엔진·대규모 컴포넌트 분할 없음.

이번에는 AI 시각 전략·콘셉트·생성 결과를 접지 않는다. 하위 실행 상태를 상위에 전달하지 않고도 안전한 정보 축소 범위만 반영했다. 더 큰 선택 패널 재구성이나 모바일 미리보기 점프/상태 집계는 별도 설계가 필요하다.
