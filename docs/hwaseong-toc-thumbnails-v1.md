# 화성시 관심분야 목차 썸네일 v1

## 범위

PR #265 기반 Staging `/samples` 목차의 이미지 표현만 변경한다. 제목과 카테고리는 기존 HTML을 유지하고 카드의 둥근 모서리·본문 여백을 공통으로 사용한다. 모든 이미지 영역은 16:9이며 390/520px에서는 화면 안쪽 여백을 제외한 카드 너비에 비례해 높이가 결정된다.

기사 이미지 블록, 원본 파일, 본문, Composition, 기사 ID, DB 정렬 및 관심분야 정렬 규칙은 변경하지 않는다. 새 자산·migration·권한·이미지 변환 서비스를 추가하지 않는다.

## 이미지별 크롭

| 기사 | 목차 표시 | 보존 사항 |
| --- | --- | --- |
| 01 생활행정 | 상·하단 문구 영역을 제외한 세 순환 과정 일러스트 중심 | 전체 순서도와 문구는 요약에 유지 |
| 02 관광 | 공식 지도 중앙을 프레임에 채움 | 가장자리 전체 지도·확대·터치 영역은 기존 요약에 유지 |
| 03 행사 | 아래쪽 전통 건물·무대 중심 | 전체 포스터는 요약에 유지 |
| 04 만평 | v3 이미지 첫 장면만 표시 | 전체 3컷과 대사는 요약에 유지; v2에는 이 크롭을 적용하지 않음 |
| 05 접근성 | QR 제거 파생 이미지의 사람·반려견 중심, 하단 기준 1.05배 | 기존 QR 제거 자산 URL 유지 |
| 06 인터뷰 | 상단 기준, 얼굴·상반신 중심 | 기존 사진 URL과 A/B 표지·상세 출처 유지 |
| 07 영상 | 기존 16:9 썸네일 전체 | 기존 재생·닫기 기능 유지 |

목차는 기사 전문을 대체하지 않는다. 크롭된 그림 속 문구보다 카드의 HTML 제목·카테고리를 탐색 기준으로 사용한다. 이미지의 `alt`는 빈 값으로 두어 같은 링크 안의 제목과 중복해서 읽지 않는다.

## 로딩 및 제한

- 기존 인증 프록시 URL을 재사용한다. 공용 URL이나 새로운 접근 경로를 만들지 않는다.
- 화면 밖 이미지는 lazy loading, 디코딩은 async를 사용한다. 16:9 프레임이 로딩 전부터 공간을 확보한다.
- CSS 크롭은 다운로드 바이트를 줄이지 않는다. 별도 파생 파일은 만들지 않았으며 원본/기존 WebP를 재사용한다.
- 사진·Canva 자산의 외부 사용 권리는 여전히 미확인이다. 비공개 시연·외부 공개 및 재배포 금지 고지를 유지한다. 이번 변경은 이용 허가 확보를 의미하지 않는다.

## 검증

- 목차 7프레임과 원본 URL 보존, 이미지별 크롭 분기, 요약/상세에 크롭 미적용: 신규 fixture 테스트 3개.
- 기존 관심분야 4종의 7개 기사 순서와 요약/상세 이동 테스트 유지.
- 전체 격리 회귀 648/648, skip 0; TypeScript, lint, Webpack build 통과. lint는 기존 경고 3개.
- 원격 확인 대상: 390/520px에서 7개 카드의 피사체·잘림·가로 넘침, 4종 정렬, 카드→요약→상세, 06 A/B, 07 재생·닫기. 브라우저 검수 자료는 PR에 연결한다.
- Production 배포·데이터 변경 없이 후속 stacked PR을 OPEN으로 유지한다.
