## 열람 및 구현 경계

기사: 같은 경로에 `?articleId=<Staging ID>`로 요약, `&view=detail`로 상세. `&width=390` 또는 `&width=520`으로 모바일 폭을 점검한다. 목록·이전 페이지·이전/다음 기사 링크는 동일 프로젝트와 폭을 유지한다.

Staging 환경·DB ref·사이트 설정 확인, 정확한 샘플 slug, 기존 HMAC 로그인·프로젝트 담당 권한을 모두 요구한다. Production과 일반 Preview에서는 비활성이다. 기존 공개 reader 및 API의 권한은 변경하지 않는다. 새 발행 방식이 아니라 비공개 제안용 표시 화면이다. 상세는 공통 `ArticleCard`·기존 Composition·폰트 CSS·글자 확대·음성 player·이미지 확대를 재사용한다. 파일은 기존 인증 proxy를 통하며 raw public Storage URL이나 signed token을 배포하지 않는다. noindex/no-follow/no-referrer로 설정한다.

외부 담당자의 무로그인 접속을 새로 허용하지 않는다. 현재 결과는 관리자/담당자 로그인 후 시연한다. 정식 발행·기관 승인·시연 토큰 생성은 하지 않는다. 이미 발행된 페이지와의 시각 차이는 공통 ArticleCard 재사용 범위와 요약용 신규 UI를 구분하여 QA 보고한다.

로컬 OS의 설치된 한국어 음성을 사용해 요약을 합성하고 업로드 음성으로 등록했다. 외부 TTS API 또는 AI 음성 생성은 호출하지 않았다. 음성 대본은 요약 안내이며 상세 원문 전체 낭독이 아니다.

## 2차 디자인 품질 보강

동일한 다섯 기사 ID와 상세 원문을 유지한다. 기사·발행 상태·순서·음성·Composition은 변경하지 않는다. 새 기사나 자산 DB 행을 만들지 않고 기존 네 요약 자산의 파일 참조만 새 버전 PNG로 교체했다. 이전 Storage 객체는 삭제·덮어쓰기하지 않았다. 관광지도는 공식 원본 파일과 1024×700 좌표계를 유지한다.

- 생활행정: 모으기 → 분리·준비 → 행정복지센터 교환의 순서형 그림과 확대 가능한 HTML 세 단계. 원문에 없는 교환 비율을 추가하지 않는다.
- 관광지도: 모바일 전체 폭, 지도 확대/전체 보기, 동일 좌표계의 터치 영역, 44px 이상 큰 선택 버튼과 장소 카드. 지도 복귀는 전체 페이지 상단 대신 지도 영역에 스크롤·포커스를 돌린다.
- 행사: 원문에 나온 루나빛축제·안곡서원 문화제·노작홍사용창작연극제의 세 주제를 호수·전통 건축·무대의 편집 일러스트와 연결한다. 임의 날짜·장소·예매 정보를 만들지 않는다.
- 만평: 입장에 신난 표정 → 뒷정리를 깨닫는 놀란 표정 → 함께 웃는 두 강아지의 세 장면. 모바일에서 대사와 동작을 구분할 수 있는 세로 3컷. 확대 이미지 외 HTML 대사도 제공한다. 창작 시연임을 표시한다.
- 한국어·English: 한국어 주요 정보 아래 영어를 보조 위계로 배치한다. 반려견 크기·QR 입장·배변 처리의 세 정보만 요약한다. 공식 영어 공고로 표시하지 않는다.

요약 앞의 반복 설명을 줄이고 이미지를 앞당겼다. 음성·출처 안내는 펼쳐 확인하며 상세기사 버튼·글자 확대·목록·이전 페이지·이전/다음 기사 경로는 유지한다. 상세는 기존 공통 ArticleCard로 표시하고 본문을 재작성하지 않는다. 그림 속 문자는 이미지 확대 및 만화 HTML 대사로 보완하되, 모든 시각 요소가 글자 크기 설정으로 확대되는 것은 아니다.

## 3차 아트디렉션: 관광·만평 두 건

기존 다섯 article ID와 원문·음성·지도 이미지·좌표를 보존하고 관광과 만평만 개선한다. 다른 세 샘플과 Composition, 기사 상태·순서는 변경하지 않는다.

관광은 공식 [화성 여행 꿀팁](https://www.hscity.go.kr/www/intro/trstMap.jsp)의 장소 소개를 근거로 별도 관광 특집 paragraph 블록을 저장한다. 기사 body의 도시 비전 원문을 덮어쓰지 않고, 인증된 샘플 상세 화면에서 관광 특집을 우선 표시하고 기존 도시 비전 원문은 보존 자료로 접어 표시한다. 일반 공개 reader의 계약은 변경하지 않는다. 두 자료를 동일 원문으로 안내하지 않는다. 특집 블록의 종류·표시 상태·출처 URL을 확인하고 HTML 문자열을 실행하지 않는다. 운영 시간·요금·이동 시간을 임의로 만들지 않는다.

관광 화면은 바다·역사·초록의 장소 선택 카드, 확대 지도에서 선택 장소 중심 이동, 정보 카드에서 해당 상세 섹션으로 이동, 지도·전화·지도 복귀를 제공한다. 원본 1024×700 이미지와 여섯 폴리곤은 유지한다. 전화번호가 없는 동탄호수공원에 전화 버튼을 만들지 않는다.

만평은 OpenAI 내장 `image_gen`으로 실제 생성한 세 장면을 사용한다. Canva는 사용하지 않았다. 보호자와 코기의 달리기 → 빈 주머니를 확인하는 당황 → 강아지가 배변 봉투를 건네는 반전으로 구성한다. 생성 이미지 원본 바이트는 수정하지 않고 CSS에서 세 컷을 나눠 표시한다. 말풍선 역할의 대사·화자는 HTML로 표시해 글자 확대에 대응한다. 이미지 확대는 전체 원본을 보여준다. 실제 화성시 시설이나 인물을 촬영한 사진이 아니며, 공식 이용 절차를 새로 만드는 내용도 아니다.

- 제작 이미지: [petiquette-v3.png](assets/hwaseong-samples/petiquette-v3.png)
- 사용 도구·프롬프트: [제작 기록](assets/hwaseong-samples/petiquette-v3-prompt.md)

Staging에는 기존 만평 자산의 참조를 새로운 불변 파일로 교체하고 관광 특집 블록 한 개만 추가한다. 기존 파일은 삭제·덮어쓰기하지 않는다. 원문·음성 및 나머지 세 샘플 불변을 전후 비교한다. 기존 요약 음성은 그대로이며 새 특집 전문이나 새 만화 대사의 낭독이 아님을 안내한다. 새 기사·발행·migration·버킷·인증·Production 변경은 없다.

## 최종 품질 보정: WebP·음성 정합성

확정한 3차 시각 디자인은 다시 생성하지 않는다. 만평의 원본 PNG(3,238,286B)를 보존하고 동일 해상도 WebP 88 파생 파일(476,376B, 85.29% 감소)을 화면에 사용한다. 원본 Storage 객체와 Git 파일의 SHA-256을 확인했다. 기존 만평 자산·이미지 블록의 표시 참조만 파생 파일로 교체하며 새 기사나 자산 DB 행은 만들지 않는다.

관광·만평 음성의 DB 대본과 기존 로컬 생성 대본이 일치하고, Storage 음성 바이트도 기존 m4a와 해시가 같음을 확인했다. 실제 내용은 1차 비공개 시연의 화면 이용 안내이며 새 관광 특집 전문이나 새 만평 대사의 낭독이 아니다. 이를 ‘기존 원문 요약 낭독’으로 재분류하지 않고 두 샘플의 요약·상세 재생 UI를 숨긴다. 파일·대본·audio row·기사 원문은 그대로 보존한다. 공통 reader·관리자 음성 계약은 바꾸지 않고 Staging 전용 샘플 표시 단계에서만 억제한다. 다른 세 샘플의 기존 음성 UI는 유지한다. 새 TTS·타입캐스트·유료 음성 API는 호출하지 않는다.

관광 특집·도시 비전 보존 원문·출처는 유지하고 지도·전화 링크를 재검증한다. 지도 위치·연락처 자료는 기존 공식 출처를 계속 사용하며 운영 시간·요금의 실시간 보장을 추가하지 않는다. 인증·비공개 상태·Production·migration·Storage 정책 변경은 없다.
