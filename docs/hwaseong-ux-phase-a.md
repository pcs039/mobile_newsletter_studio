## 측정 기준

고정 Staging의 인증된 브라우저 viewport 390px에서 각 구간을 5회 측정했다. 클릭 명령 직전부터 실제 대상 DOM 확인까지의 경과 시간이며 브라우저 조작 도구 전달 시간(약 0.28초)과 DOM 확인 지연을 포함한다. 브라우저 paint/모바일 통신망만의 순수 지연 수치로 해석하지 않는다. 대표 이미지의 로딩 완료 시간은 콘텐츠와 별도로 기록했다.

변경 후도 같은 방식·구간·횟수로 검수하고 PR 검수 자료에 전후 표를 연결한다. 실제 iPhone/Android 및 4G/저속망 측정과 구분한다. 브라우저 도구에서 RSC 세부 전송 타이밍을 제공하지 않아 이 구간은 별도 확정하지 않는다.

## 서버·클라이언트 경계

- `/samples/page.tsx`의 `force-dynamic`, Staging·프로젝트 slug 검사, 기존 관리자 인증·프로젝트 접근 검사를 유지한다.
- 처음 진입/새로고침/새 탭에서는 서버가 기존 7건·폰트·Composition을 조회한다. 같은 문서 안의 시연 링크만 Native History API와 `useSearchParams`로 전환한다. 다른 origin·프로젝트·경로, 새 탭/수정키 클릭은 가로채지 않는다.
- 기존 articleId·view·interest·width·qa URL 유지. 브라우저 뒤로/앞으로와 직접 링크를 지원한다. 관광 상세의 hash 이동도 유지한다.
- 서버 초기 조회에서 프로젝트·인증·기사/폰트·Composition 구간을 요청별로 측정한다. `qa=1`에서만 DOM 진단 속성으로 노출한다. 실제 SQL 세부 시간이나 RSC 다운로드 시간으로 오인하지 않는다.
- 비공개 데이터는 현재 인증 문서의 메모리에만 존재한다. 공개 캐시, localStorage, service worker, DB 저장을 추가하지 않는다. 새 진입 및 파일 요청은 기존 서버 권한을 계속 적용한다. 이미 내려받은 문구의 사후 회수는 보장하지 않는다.
- 시연 7건의 기존 인증 이미지 URL 중 최대 14개만 낮은 우선순위로 준비해 문서 내 디코딩 캐시를 재사용한다. 데이터 절약 모드/2G에서는 생략한다. 기존 파일·HTTP 캐시 정책·Storage를 변경하지 않는다.
- 기사/화면 이동 시 기존 음성 중단 이벤트를 발생시킨다. 자동 재생을 추가하지 않는다.

## 좌우 이동

표지 오른쪽은 첫 기사 요약, 요약 좌우는 이전/다음 요약, 상세 좌우는 이전/다음 상세로 이동한다. 첫 기사 왼쪽은 표지, 마지막 오른쪽은 비활성이다. 현재 관심분야 전체 7건 순서를 사용한다. 검색 결과만으로 기사 이동 순서를 축소하지 않는다.

일반 reader의 임계값·방향 판정과 상호작용 대상 검사를 공통 함수로 재사용한다. 지도, 영상/iframe, 링크/버튼/입력, 확대 이미지, 가로 스크롤 영역, 다중 터치·텍스트 선택·세로 스크롤에서는 페이지 스와이프를 적용하지 않는다. 반투명 버튼은 기본 표시하고 터치/포커스/hover 때 선명하게 표시한다.

## 보존과 검증

기사·블록·이미지·음성·Composition·DB 정렬·발행 상태는 변경하지 않는다. 기존 검색, 관심분야 4종, 06 A/B, 07 영상, 글자 확대를 유지한다. 신규 DB·RPC·공개 URL·발행 동작이 없다. 기존 Context/RSC 슬롯 전달이나 복제 구조를 변경하지 않는다.

Native History의 경계·검증된 URL·상세 유지·시작/끝 경계·공통 스와이프·가로 스크롤 보호 fixture 및 기존 회귀를 실행한다. 실제 터치 기기의 스와이프/OS 뒤로가기 제스처 충돌은 실기기 UAT 항목으로 남긴다.
