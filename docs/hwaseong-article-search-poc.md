# 화성시 기사 검색·탐색 PoC

## 기존 검색 조사와 재사용

`src/components/public-mobile-article-reader.tsx`의 검색은 이미 조회한 `orderedArticles`를 클라이언트에서 부분 일치로 검색한다. 제목·요약·visible paragraph 본문을 합치며, 문단이 없으면 기사 본문을 사용한다. 텍스트의 연속 공백을 합치고 검색어 앞뒤 공백을 제거하며 `ko-KR` 소문자 비교를 사용한다. 형태소 분석·번역·유사어 추론은 없다.

결과는 제목과 매칭 위치 주변 발췌문이며, 선택하면 기존 `goToArticle`로 이동하고 검색 패널을 닫는다. 일반 reader 전용 모달은 스와이프·인덱스·페이지 상태와 연결돼 있어 시연 목차에 그대로 복제하지 않는다.

제목 처리·검색 텍스트 추출·부분 일치·발췌문을 `src/lib/mobile-article-search.ts`로 추출해 양쪽에서 재사용한다. 일반 reader의 검색 필드 우선순위와 발췌 길이·선택 동작은 유지한다. 화성시에서는 PR #266의 기존 카드·16:9 썸네일을 그대로 사용한다.

## 시연 검색 범위

- 입력으로 받은 기존 시연 기사 7건만 검색한다. 추가 DB/서버 조회·검색 서비스·외부 API는 없다.
- 기사 제목·요약·저장 본문, 시연 제목·요약·카테고리, visible 문단 본문·제목을 사용한다.
- 검증된 인터뷰/영상의 인물·인용문·섹션, 관광지 설명, v3 만화 대사, 기존 접근성 영어 안내도 검색한다. 표시되지 않는 문단·이미지 경로·임의 메타데이터·원본 URL은 검색 자료로 추가하지 않는다.
- 시연용 주제어는 생활/행정/재활용, 관광/여행, 문화행사, 반려견, 접근성, 인터뷰, 영상 및 대응 영어 단어로 명시한다. 자동 번역·AI 추천이 아니다. 주제어 사전 자체는 결과 발췌문에 표시하지 않는다.
- 기존 일반 검색의 문자 부분 일치 방식을 유지한다. `dog`/`DOG`는 같다. 다단어 검색은 공백을 포함한 문구 일치이며, 오탈자·형태소·모든 언어의 번역·이미지 OCR은 지원하지 않는다.

## 관심분야와 이동

먼저 전체 7건을 기존 관심분야 규칙으로 정렬한 다음 검색 조건으로 필터링한다. 따라서 관심분야가 달라도 같은 검색어의 결과 집합은 같다. 일치한 결과의 순서만 관심분야에 따라 달라질 수 있다.

목차의 검색 입력과 결과는 컴포넌트 상태로 처리한다. 검색어를 URL·쿠키·localStorage·분석 이벤트·서버로 전송하거나 저장하지 않는다. 입력마다 라우터나 서버 조회를 호출하지 않는다. 동일 reader가 유지되는 화면 이동에서는 검색 입력이 남을 수 있으며 새로고침/재진입 시 복원은 보장하지 않는다.

결과 클릭은 기존 articleId 요약 링크이고 관심분야·폭·QA 설정을 유지한다. 상세/이전/다음은 검색 결과만의 축소 목록이 아닌 기존 관심분야 전체 7건 순서를 사용한다. `검색 종료`는 입력을 지우고 현재 관심분야의 원래 목차와 입력 포커스를 복원한다. 결과가 없으면 별도 안내와 종료 경로를 제공한다.

## 안전 경계

Staging `/samples`의 기존 환경·프로젝트·관리자 접근 검사를 유지한다. 기존 기사 ID·sort_order·본문·이미지·음성·Composition은 수정하지 않는다. migration, Storage 변경, 원격 쓰기, 운영 배포, 새로운 검색 API는 없다. 기존 사진·Canva 자산의 권리 미확인 및 비공개 시연 고지도 유지한다.

이번 범위에는 페이지 전환 속도·화살표·음성 변경을 포함하지 않는다. PR #261~#266과 기존 stash 2개는 보존하며 후속 stacked PR을 병합하지 않는다.

## 검증

- 공통 검색의 문단 우선순위·본문 fallback·공백·대소문자·문자 그대로의 검색·발췌 계약.
- 제목/요약/본문/주제/영어, 결과 없음, 검증되지 않은 메타데이터·숨긴 문단 제외.
- 관심분야 4종에서 동일 결과 집합과 기존 순서 유지, 입력/종료/포커스/링크 문맥, HTML 이스케이프.
- 기존 7건·목차 썸네일·표지·06 A/B·07 영상·일반 reader 회귀.
- 원격 검수는 고정 Staging의 인증된 브라우저에서 390/520px로 수행하고, 실기기 검사와 구분해 PR에 결과를 기록한다.
