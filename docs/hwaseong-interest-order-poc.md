# 화성시 관심분야별 기사 순서 PoC

PR #264 `e97a9155ed8e140953e5a8924b2f71f1ac4a7092` 기반 후속 브랜치다. Staging의 인증된 `hwaseong-2026-10-samples/samples`에서만 제공한다. Production·일반 Preview의 기존 route gate와 로그인·프로젝트 권한은 유지한다.

## 작업자/독자 흐름

표지 → 목차의 **어떤 소식부터 볼까요?** → 전체 보기 / 생활·행정 / 관광·문화 / 반려생활 → 바뀐 순서의 목차 → 요약 → 상세 → 이전/다음 → 목차.

표지의 기존 디자인·CTA 위치는 유지한다. 관심 선택 UI는 목차에만 둔다. 초기 URL에 선택값이 없으면 전체 보기다. 사용자의 명시적 선택만 사용하며 연령·성향을 추론하지 않는다. AI 추천이나 개인별 예측 기능으로 표시하지 않는다.

## 시연 분류와 순서

분류는 Staging fixture의 기사 ID별 코드 설정이다. DB `interest_tags`·`institution_priority`·`sort_order`를 수정하지 않는다.

기존 `getInterestOrderedArticles()`의 안정적 태그 정렬을 재사용한다. 시연용 wrapper에만 주제 태그를 부여하고 기관 우선순위를 중립값 3으로 고정한다. 실제 기사 객체의 긴급성·유효기간·날짜를 넘겨 순위를 바꾸지 않는다. 한 유형만 선택하므로 일치 여부만 점수에 반영되고, 복수 태그가 있다는 이유로 같은 일치 기사보다 더 높아지지 않는다. 동점은 repository가 제공한 원래 순서를 유지한다.

필수공지 우선순위는 주제 일치와 별도 단계로 둔다. 향후 검증된 필수 공지를 명시적으로 지정하면 전체 보기에서도 먼저 배치할 수 있다. 현재 7건은 모두 0이며 과거 자료를 재난·안전 공지로 임의 분류하지 않는다. 미분류/새 기사도 제외하지 않는다. 어떤 유형에서도 전체 기사에 접근할 수 있다.

목차 카드의 01~07 표기는 기존 샘플 식별 번호다. 기사 상단의 `n / 7`은 선택된 보기에서의 현재 위치이며 비기본 보기 이름을 함께 표시한다.

## URL·이동 계약

- 검증된 `interest=civic|culture|pets`만 전달한다. 기본 `all`은 URL에서 생략해 기존 직접 링크를 유지한다.
- 알 수 없는 값, 대소문자 변형, 중복 파라미터 배열은 전체 보기로 정규화한다. 임의 문자열을 다음 링크로 전파하지 않는다.
- 표지·목차·요약·상세·폭 전환·관광지 상세 anchor의 모든 내부 경로에 선택값을 유지한다. 표지로 복귀한 뒤 첫 기사 읽기도 해당 보기의 첫 기사로 간다.
- 이전/다음은 화면 표시와 같은 정렬 결과를 사용한다. 각 보기의 첫·마지막 기사에서는 잘못된 이전/다음 링크를 제공하지 않는다.
- `articleId`를 유지한 직접 링크는 선택한 기사 그대로 열린다. 관심 유형이 없으면 기본 순서, 있으면 그 보기의 이웃 기사만 바뀐다.
- 쿠키·localStorage·개인 프로필 저장을 추가하지 않는다. URL은 선택한 보기만 전달한다. 분석 이벤트·로그인·식별자 수집을 추가하지 않는다.

서버는 기존 접근 검사 뒤 관심 enum 문자열만 client component에 전달한다. Context/RSC 슬롯이나 저장 API는 변경하지 않는다. 정렬은 복사한 wrapper 배열에 수행하고 기존 기사 객체·필드·이미지·음성·Composition은 바꾸지 않는다. 일반 공개 reader의 기존 관심 설정·정렬 계약도 수정하지 않는다.

## 검증 계약

- 네 가지 순서·모든 7건 유지·입력 불변·복수 태그·동점·미분류·날짜 미반영·필수공지 독립 순서를 격리 테스트한다.
- 네 보기 × 7건 × 요약/상세 렌더링에서 이전/다음·목차·표지·동일 요약 복귀의 articleId·interest·폭·QA 문맥을 확인한다.
- cover callback의 첫 기사/목차 목적지와 서버의 잘못된/중복 query 정규화도 검사한다.
- 05의 QR 없는 기존 WebP는 새로 생성하거나 교체하지 않는다. 기존 #264 Staging 요약에서 표시를 사전 확인한다.
- 원격 고정 Staging에서는 390/520 브라우저 폭에서 관심 선택·목차 순서·실제 링크 이동·06 A/B·07 재생/닫기를 점검한다. 실제 iPhone/Android UAT는 별도 미실시 상태를 유지한다.
- 데이터 보존은 #264 보정 완료 상태와 읽기 전용으로 비교한다. DB/Storage 쓰기·migration·기사 추가·발행은 실행하지 않는다.
