# 화성시 시연 UX Phase C — 별도 OpenAI 기사 낭독

## 경계

고정 Staging 환경 식별자와 프로젝트 UUID가 모두 일치하고 기존 프로젝트 관리자 인증을 통과해야 API를 사용할 수 있다. Production/일반 Preview/다른 프로젝트는 404이며, 생성 POST는 기존 same-origin 검사도 유지한다. API 키는 서버 환경에서만 읽는다. migration·버킷·환경변수·기존 업로드/TTS API는 변경하지 않는다.

원본 기사와 기존 음성 5건은 변경하지 않는다. 신규 `newsletter_audio_files`만 사용하며 **article_id는 null**이다. 기존 일반 reader가 article_id로 업로드 음성을 고르는 동작을 방해하지 않기 위해서다. 시연 전용 ID→음성 인덱스가 현재 대본·모델·음성 해시와 일치하는 완료 자산만 연결한다. 요약과 상세는 같은 현재 기사 해설을 사용한다. 07은 영상 원음과 구분한다. 02는 관광 특집만 낭독하며 보존 도시 비전은 제외한다. 04는 현재 만화 대사와 원문을 사용한다.

01 Marin / 02 Cedar / 03 Onyx / 04 Coral / 05 Marin / 06 Cedar / 07 Onyx. 검색·관심분야 정렬과 무관하다. 표시 중인 한국어·영어와 실제 원문/특집에서 대본을 만들며 임의 요약 생성은 하지 않는다.

## 제작 및 비용

`?qa=1`의 내부 QA 영역에서 설정·요청 상태를 확인하고 네 짧은 한국어 음성을 먼저 생성한다. 이후 기사별로 명시적으로 실행한다. 미리보기·페이지 진입·상태 GET은 유료 생성을 실행하지 않는다. 같은 음성/대본/모델의 결정적 UUID를 기존 테이블 PK로 먼저 예약하므로 동시 요청도 최대 한 요청만 생성한다. 한 요청은 1,200자 단위로 분할하고 전체 대본 16,000자 상한을 둔다.

OpenAI 공식 문서: [음성 가이드](https://developers.openai.com/api/docs/guides/text-to-speech), [모델](https://developers.openai.com/api/docs/models/gpt-4o-mini-tts), [가격](https://developers.openai.com/api/docs/pricing). 요청 모델은 `gpt-4o-mini-tts`, 형식은 MP3, 기본 생성 속도는 API 기본값 1이다. 차분하고 또렷한 한국어 낭독과 원문 외 추가/요약 금지 지시를 기존 서버 모듈에서 재사용한다. 입력 $0.60/백만 text tokens, 출력 $12/백만 audio tokens 기준이며 실제 청구액은 계정 usage 확인 전 확정할 수 없다. 음성 응답에서 사용량을 반환하지 않으므로 호출 수·문자 수·파일 크기를 별도로 기록한다. 공식 문서의 모델 종료 예정일(2027-01-06)은 후속 유지보수 위험이며 이번 요청 모델을 임의 대체하지 않는다.

## 파일 및 결과 불명

새 파일은 `audio-files/projects/<Staging UUID>/sample-tts-v1/<request UUID>/<segment>.mp3`에 `upsert=false`로만 저장한다. 기존 파일 삭제·덮어쓰기 없음. 실제 MP3 응답을 재다운로드해 크기·SHA-256을 비교한 뒤 새 행만 완료 처리한다. manifest/segment는 같은 관리자 인증·프로젝트 검사, 행 소속·현재 대본 해시·경로 검사, private/no-store를 적용하고 Range를 전달한다.

응답 유실 시 같은 결정적 ID로 상태를 조회한다. DB 완료 후 응답 유실은 기존 ready 결과를 돌려주며 OpenAI를 재호출하지 않는다. pending/Storage 성공 DB 실패/중단은 **결과 불명**으로 유지한다. 자동 재시도·자동 파일 정리·추측 완료 처리 없음. 운영자가 해당 요청 ID의 행·분할 파일·해시·호출 기록을 읽기 전용으로 대조한 후 별도 승인된 복구를 해야 한다. 현 단계에서 불명 요청을 새 ID로 우회 재생성하는 버튼은 없다. 완전한 영속 작업 큐/재개 API는 이번 범위가 아니다.

## 검수 한계

브라우저 재생·파일/대본·음성 ID·속도·이동 시 중단은 검증 가능하다. 한국어 자연스러움과 영어 발음의 최종 청취 평가는 실제 청취와 구분해 기록한다. 실제 iPhone/Android 및 이동통신망 검증은 브라우저 시뮬레이션으로 대체하지 않는다. 사진/Canva 권리 제한 및 비공개 인증을 그대로 유지한다.
